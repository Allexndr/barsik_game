# 🐱 Путешествие Барсика — Игровая платформа

HTML5-игра для бренда BARSIK. Работает в браузере на телефоне, планшете и компьютере.

## Запуск

```bash
cd barsik-game
python3 -m http.server 8090
```

Откройте `http://localhost:8090` в браузере.

## Структура

```
barsik-game/
├── index.html          # Главная страница
├── css/style.css       # Все стили
├── js/
│   ├── data.js         # Миры, уровни, друзья, награды
│   ├── storage.js      # Сохранение/загрузка в localStorage
│   ├── screens.js      # UI экранов (меню, карта, коллекция и т.д.)
│   ├── gameplay.js     # Canvas-геймплей (runner/собиратель)
│   └── app.js          # Инициализация и навигация
├── assets/             # Изображения (фоны, иконки, персонаж)
└── README.md
```

## Экраны

- **Загрузка** — прогресс-бар с предзагрузкой изображений
- **Главное меню** — кнопки: Играть, Город Друзей, Коллекция, QR-сундук, Рейтинг, Профиль
- **Выбор сложности** — Лёгкое (3–7 лет), Смелое (7–10 лет), Суперпутешествие (11+)
- **Карта путешествия** — 6 тематических миров с иконками
- **Выбор уровня** — сетка уровней по миру (всего 100)
- **Геймплей** — runner с 3 дорожками, сбор звёзд и друзей, прыжки
- **Город Друзей** — визуализация города, растущего с каждым другом
- **Коллекция** — 20 друзей (common/rare/legendary)
- **QR-сундук** — анимация открытия с фейерверком и случайной наградой
- **Рейтинг** — дружеский рейтинг (без проигравших)
- **Профиль** — статистика, костюмы, реальные призы

## Управление

- **Свайп вверх/вниз** — смена дорожки
- **Тап / свайп вправо** — прыжок
- **Стрелки/W/S** — клавиатура (десктоп)

## Механики по ТЗ

- 100 уровней, 20–40 секунд каждый
- Управление одним пальцем
- Новый друг каждые 5 уровней (20 друзей)
- Звёзды дружбы за уровни, ежедневный вход, QR
- Город Друзей развивается: домики, парк, кафе, фонтан, аттракционы
- QR-сундук: всегда есть подарок, фейерверк-анимация
- 3 уровня сложности (возраст не спрашивается)
- Костюмы за звёзды
- Реальные призы на уровнях 20/40/60/80/100
- Сохранение прогресса в localStorage
- Ежедневный бонус за вход
