## 📺 Что это?

**BARSIK LAND** — браузерная игра для детей 5–12 лет о дружбе, приключениях и волшебных сундуках. 

**Главная идея:** 
> Барсик ищет друзей в волшебных мирах. Каждый найденный друг поселяется в городе. QR-коды на упаковке сладостей BARSIK открывают магические награды.

**Референсы:** Club Penguin, Poptropica, Moshi Monsters, Secret Builders (но это наш уникальный мир).

---

## 🎮 Как играть

```
1. Вход → Регистрация (ник, пол, возраст, телефон, язык)
2. Попадаёшь в Город Барсика (3D хаб как главное меню)
3. Кликаешь на Путешествие → видишь карту с 100 уровнями
4. Выбираешь уровень → запускается 3D-эпизод (20–120 сек)
5. Решаешь головоломки, помогаешь персонажам
6. Получаешь награду: звёзды дружбы + новый друг
7. Друг появляется в городе (домик, анимация)
8. Повторяешь — город растёт, друзей становится больше
9. Находишь QR-код на упаковке → открываешь сундук → получаешь редкого друга
10. Собираешь 100 уровней → суперприз! 🎁
```

## 🏗️ Архитектура (готова!)

### Tech Stack
- **React 18** — компоненты, состояние
- **Vite** — быстрая сборка, hot reload
- **TypeScript** — типизация
- **Zustand** — управление состоянием (игрок, друзья, город)
- **Three.js** — 3D сцены (города, эпизоды)

## 📋 Сценарий 1-го сезона ("Первые друзья")

### Структура
- **6 миров**, **10 уровней** в каждом = 60 уровней
- **2 главных друга** в 1-й арке: Путало (Поучитель) + новый персонаж
- **Короткие эпизоды** 20–120 сек (не долгие)
- **Механика:** исследование, поиск, помощь, выбор маршрута
- **Казахский колорит:** горы, юрты, орнаменты, традиции

### Миры (гл. 1–6)
1. 🍓 **Фруктовый лес** — первые шаги, встреча Путало
2. ❄️ **Ледяная долина** — тепло дружбы, забота
3. 🥤 **Город Колы** — современный город, турниры
4. 🌈 **Радужная страна** — магия, редкие друзья, цвета
5. 🏔️ **Горы Барсика** — преодоление, альпинизм
6. 🎉 **Город Друзей** — финал, большой праздник

**Документация:** `docs/BARSIK_GDD_v2.md`, `docs/BARSIK_ARC1_OUTLINE.md`, `docs/` (все подробно).

## 🎁 QR & Монетизация

### QR-сундук
- QR находится на **реальной упаковке** BARSIK
- Сканируется через камеру браузера
- **Магическая сцена:** волшебный сундук + частицы + награда
- Открывает: **редкого друга**, **украшения**, **звёзды**, **в раннем этапе — внутриигровой билет**

### Реальные призы (позже)
- 20 уровней → наклейки
- 40 уровней → кружка
- 60 уровней → футболка
- 80 уровней → рюкзак
- 100 уровней → **главный приз** (розыгрыш или набор)

**Суть:** привести детей в игру через историю и дружбу, не через насильственную монетизацию.

## ❓ FAQ

**Q: Могу ли я разрабатывать локально?**  
A: Да! `npm run dev` запустит dev-сервер. Все изменения live-reload.

**Q: Где 3D моделиемы?**  
A: В `src/three/` (пока заготовки). Будут загружены GLB/GLTF из `public/assets/`.

**Q: Как добавить новый уровень?**  
A: Создай JSON в `src/utils/levels/`, загрузи в EpisodeScreen, готово!

**Q: Почему не Roblox?**  
A: Потому что браузер, быстрая загрузка, мобила работает лучше. 3D достаточно для MVP.

**Q: Когда QR будет работать?**  
A: Когда будут готовые упаковки + физический печать. А пока тестируем вовлечение через историю.
