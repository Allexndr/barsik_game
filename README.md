# Путешествие Барсика

Детская браузерная 3D-игра о путешествии Барсика, поиске друзей и небольших заданиях. Первый сезон состоит из 17 уровней (`L0–L16`) в двух главах: «Фруктовый лес» и «Ледяная долина».

## Запуск и проверки

Нужен Node.js `20.19+` (или `22.12+`) и npm. Установка зависимостей — `npm ci`, локальный запуск — `npm run dev`. Vite использует базовый путь `/game/`; локальная игра доступна по адресу `http://localhost:8765/game/`.

```sh
npm ci
npm run dev
npm run type-check
npm run lint
npm test
npm run test:e2e
npm run build
```

Для локальной проверки сцен есть dev-ссылки `?mission=0..16&lang=ru&qa=1`. Это тестовый вход, не пользовательская навигация. Playwright запускает локальный Vite-сервер и использует тестовые ответы аккаунтного API; полный прогон игры и проверка реального мобильного устройства остаются отдельными QA-задачами.

## Структура

- `src/App.tsx`, `src/main.tsx` — вход приложения и экраны.
- `src/components/` — интерфейс, карта путешествия и меню.
- `src/store/` — состояние профиля, прогресса и экранов.
- `src/three/` — 3D-сцены уровней, хаба, персонажей и окружения.
- `src/net/` — аккаунтный API и синхронизация прогресса.
- `public/assets/` — модели, изображения, звук и другие игровые ресурсы.
- `server/` — отдельный локальный API аккаунтов и конфигурация для существующего SQLite/nginx окружения.
- `tests/` — unit/integration и Playwright-проверки.
- `docs/` — спецификации, операционные заметки, актуальные решения и архив аудитов.

## Точки входа и данные

Карта и награды настроены в `src/utils/levels.ts`; реализация сцен находится в `src/three/scenes/`. Клиентский прогресс сохраняется с привязкой к ID игрока. Аккаунтный API хранит профиль и прогресс в SQLite; для его самостоятельной установки используйте `server/package.json`. Не переносите реальные секреты в исходники или Git.
