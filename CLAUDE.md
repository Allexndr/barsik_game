# BARSIK — контекст проекта

Браузерная 3D story-adventure для детей 5–12 лет. Бренд сладостей из Алматы.
React 18 + Vite + TypeScript + императивный Three.js. RU + KK.

Каждая строка ниже существует потому, что без неё уже ошибались.
Если правило не предотвращает конкретную ошибку — его здесь быть не должно.

---

## Канон: 17 уровней, не 100

Сезон 1 — **L0–L16, два мира**: Фруктовый лес (L0–9), Ледяная долина (L10–16).

Устаревшее, чего в проекте больше нет (`BARSIK_SEASON_1_FULL_SPEC` §«Не использовать»):

- «100 уровней», карта 10×10, 40 stub-уровней
- «Новый друг каждые 5 уровней» — друг выдаётся как **награда квеста**
- «20–40 секунд на уровень» — цель **3–6 минут**, минимум 4 игровых бита
- «6 миров обязательны в S1» — играбельны 2, остальные тизер на карте
- Canvas-раннер, три полосы, lane-механики

Иерархия источников при конфликте:
`GDD > MissionNScreen > сцены > levels.ts`.
Полная спека: `output/doc/BARSIK_SEASON_1_FULL_SPEC.docx`.

## Герой: скелет есть, анимации есть

`barsik_cool_rigged.glb` (основная) и `barsik.glb` (запасная) — **skin 1,
3 клипа: Idle, Walk, Wave**. `loadCharModel` подхватывает их сам.

Раньше здесь стоял открытый блокер O2 «0 анимаций, 0 skins». Он закрыт
(проверено `scripts/probe-glb.mjs` 09.09.2026). Порядок выбора модели —
`barsik_cool_rigged → barsik_rigged → barsik`, см. `BaseLevelScene.ts:60`.

Что осталось от той истории и остаётся верным: quad-генерации Meshy и
TRELLIS дают кота на четырёх лапах и для героя не годятся — нужна
двуногая модель в T-позе. Процедурный `PlushBarsik` анимируется, но на
Барсика не похож, и остаётся только запасным вариантом.

## 3D-сцены: чего не делать

**Не ставить `setupGround()`** — это плоская плоскость, из-за неё 15 уровней
выглядели дёшево. Использовать `setupForestEnvironment()` /
`setupWinterEnvironment()`: они дают скульптурный рельеф, небо, туман, траву.

**Не ставить объекты на `y = 0`.** Земля рельефная. Использовать
`this.groundHeightAt(x, z)` или `this.snapToGround(obj)`.

**Не звать `placeMany` напрямую** — используй `this.placeProps(loader, [...])`.
`placeMany` только добавляет меш в сцену; `placeProps` ещё и навешивает
коллайдер. Иначе герой проходит сквозь брёвна, лавки и палатки.

**Внутри сэмплера рельефа звать только `trail.flatPointAt()`**, не `pointAt()`.
`pointAt` спрашивает высоту у рельефа, а рельеф спрашивает маршрут у тропы —
получается бесконечная рекурсия и белый экран.

**Не добавлять ambient-свет.** Рига выставлена примерно 4:1 ключ/заливка.
Раньше было 1.9:1 — отсюда «засвеченная плоская» картинка.

**Маркер горит только у активной цели.** Подсвеченные разом пять целей
превращают поле в лес леденцов и не указывают никуда.

## Мобильный — основная платформа

Дети играют с телефона. `this.viewport` различает три режима:
`portrait` / `phone-landscape` / `wide`. Отступы камеры брать из
`this.cameraFraming()`, не писать `isPortraitViewport() ? a : b` —
так лежащий телефон попадает в десктопную ветку.

Режим определяется **по высоте**, не по media-фиче `orientation`:
маленькое окно на десктопе — тоже «landscape», но ему нужна десктопная подача.

## Supabase: клиент только читает

`barsik_leaderboard` — представление над таблицей `barsik_saves`.
В клиенте **нет ни одного вызова записи**, и так должно остаться: anon-ключ
лежит в публичном бандле. Права закрыты миграцией
`supabase/fix_leaderboard_rls.sql` (аудит 2026-08-04: anon мог писать и
удалять чужие сейвы).

Когда появится облачная синхронизация — только через edge function с
service-role ключом, никогда из браузера.

## Как запускать и проверять

```bash
npm run dev                      # http://localhost:5173
npx tsc --noEmit                 # типы
npm run build                    # полная сборка
```

Прямой запуск уровня в dev: `http://localhost:5173/?mission=12`
(работает только при `import.meta.env.DEV`, см. `App.tsx`).

## Тон и содержание

- **Нет проигрыша.** Ошибка — обучение: «попробуй ещё», не «ты проиграл».
- **Нет pay-to-win** и покупок за реальные деньги.
- Казахский колорит — горы, орнамент, тюбетейка, домбра, юрта — **деликатно**,
  через дружбу, без фольклорного перегруза.
- Тексты только RU и KK. Утёкшие языки — баг.
- Каждый уровень = помочь кому-то. Путало не злодей, а одинокий друг.
