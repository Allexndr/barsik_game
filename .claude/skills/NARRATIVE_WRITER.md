# Narrative Writer Skill для BARSIK

## Задача
Создать связный нарратив для игры, где Барсик путешествует через 6 миров, встречает друзей, развивает город.

## Структура нарратива
### Основная сюжетная линия
Барсик начинает в Фруктовом лесу и путешествует через все 6 миров, собирая друзей и строя город дружбы.

### Пер персонажи (20+ друзей)
Каждый имеет:
- Имя, профессию (музыкант, спортсмен, учёный и т.д.)
- Короткую историю (2-3 предложения)
- Редкость (обычный, редкий, легендарный)
- Казахский элемент в образе

### Диалоги
- Приветствия Барсика
- Линии перед уровнем (мотивация)
- Линии после победы (поздравления)
- Линии разблокировки друзей

## Примеры персонажей
- **Барсик-музыкант** — играет домбру, тюбетейка с орнаментом
- **Барсик-спортсмен** — бегун, спортивный костюм с казахским узором
- **Барсик-учёный** — очки, блокнот, открывает секреты гор

## Контрольные точки
- Каждые 5 уровней = новый друг + малый нарратив
- Каждый мир имеет финальную сцену/диалог
- Финальный мир (100) = большой праздник

## Как использовать
```
/barsik-narrative [action] [scope]
```

### Примеры
- `/barsik-narrative characters-generate` — создать всех 20+ персонажей
- `/barsik-narrative main-story` — основной сюжет из 6 актов
- `/barsik-narrative dialogues-world 2` — диалоги для мира 2 (Ледяная долина)
- `/barsik-narrative lore-kazakh` — создать казахский лор

## Выводы
- Full narrative bible (100+ страниц)
- Все диалоги в JSON
- Профили персонажей
