# BARSIK Level Designer — compatibility entry

Перед аудитом или изменением уровня полностью прочитай:

1. `.agents/skills/barsik-game-director/SKILL.md`;
2. `CLAUDE.md`;
3. `docs/CANON_RECONCILIATION.md`;
4. `docs/S1_GAMEPLAY_5MINUTE_IMPLEMENTATION.md`, если файл существует.

Текущий Season 1 состоит из L0–L16. Для каждого затронутого уровня обязательны:
текущий маршрут, проблемы по категориям, план до кода, законченный малый патч и
реальный QA обычным вводом на desktop и телефоне. Пространственные ограничения
должны быть видимыми, а камера, коллизии и цель — понятными игроку.
