# Level Designer Skill для BARSIK

## Задача
Спроектировать и наполнить 100 уровней в 6 мирах так, чтобы:
- Каждый уровень был интересным (~20-40 сек)
- Кривая сложности была плавной
- Каждый мир имел свою тему и визуальность
- Собирались друзья каждые 5 уровней

## Структура миров
1. **Фруктовый лес** (1-15 ур.) — лёгкий старт, радугозвёзды
2. **Ледяная долина** (16-30 ур.) — средняя сложность, зимний мотив
3. **Город Колы** (31-45 ур.) — современный город
4. **Радужная страна** (46-60 ур.) — волшебство, яркие цвета
5. **Горы Барсика** (61-75 ур.) — приключение, горы
6. **Город Друзей** (76-100 ур.) — финальная celebrация

## Каждый уровень содержит
- Номер и название
- Мир (1-6)
- Тип механики (сбор, избегание, прыжки, паззл)
- Сложность (1-10)
- Время (20-40 сек)
- Конфиг препятствий
- Конфиг бонусов
- Нарратив/лор

## Как использовать
```
/barsik-level-design [action] [params]
```

### Примеры
- `/barsik-level-design generate-all` — сгенерировать все 100 уровней
- `/barsik-level-design difficulty-curve` — проверить кривую сложности
- `/barsik-level-design world-theme 3` — описать мир 3 (Город Колы)
- `/barsik-level-design friend-unlock-schedule` — расписать разблокировку друзей

## Выводы
- JSON конфиги всех уровней
- Таблица прогресса
- Сценарий для каждого уровня
