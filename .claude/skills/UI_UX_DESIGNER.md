# UI/UX Designer Skill для BARSIK

## Цель
Превратить интерфейс из "дешёвого" в премиум-класс. Мягкие формы, чёткая иерархия, адаптивность.

## Ключевые экраны для переделки
1. **Main Menu** — вход в игру
2. **Game Map** — большая карта с 6 мирами
3. **Level Screen** — геймплей
4. **Level Complete** — завершение уровня + награды
5. **Friends Collection** — коллекция друзей
6. **City Screen** — город Барсика
7. **Shop** — магазин звёзд дружбы
8. **Leaderboards** — рейтинги
9. **QR Chest** — волшебный сундук

## Дизайн-принципы
- Мягкие округлые формы (но не "мультяшные")
- Премиум дети-фокусированный стиль
- Казахский колорит в деталях (орнаменты)
- Без давления на покупки
- Большие touch targets (48dp+ на мобильных)

## Палитра
- Основной: солнечные тёплые оттенки
- Акценты: казахские краски (красный, синий, зелёный)
- Фон: чистые, контрастные цвета

## Адаптивность
- **Мобильный** (320-480px): вертикальный layout
- **Планшет** (768-1024px): 2-колонный, сбоку панели
- **Десктоп** (1280px+): полный функционал

## Файлы для изменения
- `src/components/UI/` — компоненты
- `src/styles/` — стили
- `src/layouts/` — макеты экранов

## Как использовать
```
/barsik-ui-redesign [screen-name] [aspect]
```

### Примеры
- `/barsik-ui-redesign main-menu` — переделать главное меню
- `/barsik-ui-redesign responsive-check` — проверить адаптивность
- `/barsik-ui-redesign color-system` — улучшить цветовую систему
