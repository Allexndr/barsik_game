# BARSIK agent setup

Этот исторический setup-файл заменён единым workflow и больше не является
самостоятельной инструкцией.

Актуальные точки входа:

1. `AGENTS.md` — правила репозитория и маршрутизация;
2. `CLAUDE.md` — правила Claude Code;
3. `.agents/skills/barsik-game-director/SKILL.md` — обязательный workflow
   гейм-директора;
4. `docs/CANON_RECONCILIATION.md` — продуктовый канон;
5. `docs/WORKLOG.md` и `docs/decisions/` — история изменений и причин.

Перед изменением игры агент обязан проанализировать живой код и реальный игровой
маршрут, составить план, внести небольшой законченный патч и пройти QA обычным
пользовательским вводом на desktop и телефоне.

Старые генеративные команды и прежние числовые обещания из этого файла отменены.
