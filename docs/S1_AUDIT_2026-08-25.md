## 1. Инструмент аудита был слеп к камере — почему прошлые прогоны это не видели

`window.__audit()` проверяет, теряет ли камера героя в кадре, синтетически
телепортируя его в углы игровой зоны через `devTeleport()`. Но
`devTeleport()` не взводил `hasTakenFirstStep` — флаг, которым уровни
отпускают камеру из вступительного кинематографа. Для любого уровня с
паттерном «кинематограф до первого шага» синтетический прогон навсегда
оставался в залоченной камере, которая по определению не следит за героем
— и находил `hero-off-frame` даже там, где реальный игрок ничего подобного
не увидит.

**Исправлено**: `devTeleport()` теперь тоже считается первым шагом
(`src/three/scenes/BaseLevelScene.ts`). После этого прогон стал измерять
настоящую камеру следования, а не залоченную — и вот что он увидел.

## 2. Системный баг камеры — 13 из 17 уровней

Проверка: `if (this.phase === 'intro') { /* залоченная камера */ }` —
без ограничения по `hasTakenFirstStep`, значит ребёнок, который начинает
двигаться сразу, держит камеру залоченной на фиксированный кадр **весь
оставшийся таймер вступления** (несколько секунд), а не один плохой кадр.
Уже было исправлено для L2 и L8 отдельными коммитами ранее; L16 исправлен
в этой сессии раньше сегодня. Остальные 13 — нет.

| Уровень | До фикса (`worst |x|`, порог 1.0) | После |
|---|---|---|
| L0 Первое утро | не проявлялся | 0 (защита добавлена профилактически) |
| L3 Потерявшийся ёжик | 68.71 | 0 |
| **L4 Качающийся мостик** | **850.40** | **0** |
| **L5 Корзина для белочки** | **475.27** | 0.85 (погранично, не блокирует) |
| L6 Лесная загадка | 32.30 | 0 |
| L7 Встреча с Путало | 3.92 | 0 |
| L9 QR-сундук | 1.47 | 0 |
| L10 Прощание с лесом | 4.03 | 0 |
| L11 Ледяная поляна | 2.74 | 0 |
| L12 | 2.62 | 0 |
| L13 Ледяные скульптуры | 3.41 | 0 |

Разброс важен: L4 и L5 (850 и 475) — не «слегка увели камеру», это
катастрофический выход за кадр, который реальный ребёнок увидел бы в
первые секунды уровня, если бы сразу начал двигаться. Остальные — от
пограничных (1.47) до заметных (68.71), но все — один и тот же баг, не 13
разных.

**Исправление**: одна и та же правка во всех 13 файлах —
`if (this.phase === 'intro' && !this.hasTakenFirstStep)`, с коротким
комментарием, ссылающимся на L2/L8/L16 как прецедент. Дальше — только
подтверждено, не предположено: пересобрано, типы чисты, и каждый из 17
уровней перепрогнан живьём в браузере после фикса.

## 3. Два реальных, отдельных от камеры дефекта — найдены и закрыты

### L9 «QR-сундук»: четыре золотых меша рендерились чёрными

Тот же класс, что уже чинился на L16 в этой сессии: `metalness` без
`envMap` — в игре нет карты окружения, металлу нечего отражать. Замок
сундука (`makeChest`, `metalness: 0.7`) и три золотые печати у святилищ
(`metalness: 0.65`, создаются в цикле по `SHRINES`) — все четыре снижены до
`metalness: 0.12`, свечение (`emissive`) увеличено, чтобы золотой цвет
держался за счёт него, а не отражений. Подтверждено: `__audit()` больше не
находит ни одного металлика без карты окружения на этом уровне.

### L16: зарытые пропсы и тот же класс чёрного металла

Уже описано и закрыто раньше в этой сессии (стрелки-указатели на снежном
склоне, два из пяти ждущих друзей, замок сундука). Перепроверено сегодня
повторно — держится.

## 4. Находки аудита, проверенные и подтверждённые ложными тревогами

Правило сессии: ложная тревога разбирается по объекту, а не списывается на
глаз. Три группы:

**Дальний горный фон.** Повторяется почти на всех уровнях под одними и
теми же координатами (≈(-46,-66), (44,-62), (-48,-70)…) — группа из шести
конусов (серая «скала» + белая «снежная шапка», парами) далеко за игровой
зоной. Проверено по геометрии и цвету (`ConeGeometry`, `74879d`/`eaf6ff`)
— декоративные горы на горизонте, ровно за порогом, которым зонд отсекает
дальний фон. Не баг.

**L4: 44 «зарытых» пропса.** На поверку — камни (`Mesh_rock_largeA`,
цвета `9c7850`/`6ba64d`) на дне ущелья под самим мостиком, на 1.4–7.5 м
ниже уровня моста. Уровень называется «Качающийся мостик» — дно ущелья под
верёвочным мостом и должно быть далеко внизу. Не баг, это то самое дно,
через щели которого его и видно.

**L11/L12: «scene has no `nearestInteract()`».** Известное и раньше
ограничение инструмента (см. §32 плана, `L11, L12 | — | 0`), не новое.
