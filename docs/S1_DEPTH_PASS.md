# S1 Depth Pass — честный аудит + цели ≥5 мин

> 2026-08-03 · **Не playtested в браузере end-to-end.** Оценки по коду фаз/интеракций.

## Правда

Агент **не** прошёл все 17 уровней руками. Автотестов уровней нет.  
Канон `SEASON_1_FULL_SPEC`: **3–6 мин** first clear. Заказчик (GDD): короткие «мелькают» → нужен **эпизод ~5+ мин** с ≥4 битами.

## Рейтинг (тонкие → богатые)

| Уровень | ~мин | Статус | Действие depth-pass |
|---------|------|--------|---------------------|
| City hub | <1 | thin | позже: клики по друзьям |
| L9 сундук | 1.5–2.5 | thin | **3 печати + ключ + открытие** |
| L16 финал | 2–3 | thin | **prep party → сундук → фото** |
| L6 загадки | 2–3 | thin | **сбор улики → загадка ×3** |
| L10 прощание | 2.5–3.5 | thin | **подарок + прощание ×4** |
| L14 шарф | ~3 | medium | warmth жёстче + больше сугробов |
| L0–L5, L8, L12–13 | 3–6 | medium–rich | polish later |

## Целевой скелет эпизода (≥5 мин)

1. Intro VO/текст (30–40с)  
2. Explore / collect (90–120с)  
3. Core mechanic rule-of-three (120–180с)  
4. Character beat + outro (40–60с)  
5. Optional bonus stars (не блокирует)

## Сюжетный каркас (без переписывания канона)

Тот же сезон «Первые друзья»: помочь → позвать → сундук → зима → финал.  
Depth-pass **добавляет биты**, не ломает ID уровней / unlocks / keys.
