# Онбординг и регистрация (progressive) — обновлено 2026-07-19

> Статус: **канон** · не давить форму на первом экране

---

## Поток

```
[Лендинг: hero + «Начать игру»]
    → Быстрый старт: только ник + пол Барсика (~10 сек)
    → Сразу игра (карта / город / эпизоды)
    → ~1 мин игры → soft-модал «телефон, чтобы не потерять» (можно «Позже»)
    → После 5 уровней без телефона → второй soft-модал (можно «Позже»)
    → Позже (есть телефон + ≥8 уровней) → почта родителя (можно «Позже»)
```

## Почему так

- 16.07: сначала поиграть → потом дособрать профиль  
- Онбординг не должен напрягать; контент в первые 1–5 минут не теряется локально  
- Телефон = ключ к сейву в БД (и recovery); кэш ника + soft uniqueness на устройстве  
- Почта — позже, не для малышей на старте

## Поля

| Когда | Поле |
|-------|------|
| Старт | ник (уникальность soft), пол |
| ~1 мин / 5 ур. | телефон |
| После телефона + прогресс | email |
| Позже | возраст / VO язык |
