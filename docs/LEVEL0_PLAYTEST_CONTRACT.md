# Level 0 «Тропа домбры» — контракт первого прохождения

**Статус:** активный QA-контракт · 2026-08-11
**Сцена:** `src/three/scenes/Level0Scene.ts` через `Mission0Screen`
**Канон:** `docs/CANON_RECONCILIATION.md` C15 — не возвращать старый квест с
яблоками.

## Обещание игроку

Это первый эталонный вертикальный срез BARSIK LAND: мягкое приключение на
4–6 минут, без смерти, таймера на поражение и наказания за ошибку. Барсик
слышит оборванную домбру и по пути к юрте делает мир лучше.

1. Идёт на звук и учится двигаться.
2. Поднимает три фонаря и видит, как оживает тропа.
3. Перепрыгивает ручей; промах — безопасный «плюх» и возвращение, не проигрыш.
4. Закрепляет три полотнища войлока на юрте.
5. Входит внутрь и повторяет ритм домбры.

Уровень начинается только после осознанного нажатия «Играть».

## Контракт стартового экрана

`Level0Scene.init()` может подготовить и нарисовать мир, но до нажатия
«Играть» его симуляция обязана быть поставлена на паузу. Это означает:

- `assetsReady` лишь открывает кнопку; не запускает интро;
- экран может ждать сколько угодно — первая реплика, подсказка движения и
  временные биты не должны уйти за ним;
- при нажатии сцена снимается с паузы ровно один раз; базовая сцена сдвигает
  временные маркеры на длину паузы, поэтому первая реплика начинается после
  нажатия;
- глобальная пауза приложения остаётся отдельным состоянием: она не должна
  открывать настройки только из-за стартового экрана.

## Минимальный регрессионный прогон

Проверять на чистом профиле или после сброса прогресса. В dev-сборке доступен
`window.__level` только для чтения этого прогона; он не является игровым API.

| ID | Действие | Ожидаемый результат |
|---|---|---|
| G0 | Открыть `?mission=0`, дождаться «Играть», не нажимать 2 с | `paused=true`, `phase='intro'`, `introI=0`; нет смены реплики за оверлеем. |
| G1 | Нажать «Играть», подождать 1.2 с | `paused=false`; начинается первая интро-реплика (`introI >= 1`). |
| G2 | Пройти фонари | Каждый фонарь даёт свет, звук и понятный счётчик 1/3 → 3/3. |
| G3 | Проверить ручей | Все камни достижимы; падение возвращает без потери прогресса. |
| G4 | Войти в юрту, повернуть камеру | Камера остаётся внутри, не выходит наружу и не клипует стены. |
| G5 | Пройти ритм неверно | Фраза повторяется спокойно; нет «поражения» и сброса уровня. |
| G6 | Пройти с выключенным звуком | Визуальные стрелки, счётчики и подсказки сохраняют понятный путь. |

## Кадры, которые обязан выдержать уровень

1. Тёплая поляна и Барсик у начала пути — читается цель по звуку/стрелке.
2. Первый поднятый фонарь — тёплый свет контрастирует с лесной прохладой.
3. Камни через ручей — ясный маршрут и безопасная ширина прыжка.
4. Юрта с полотнищами — главный казахстанский образ с понятной точкой работы.
5. Интерьер и домбра — финальная награда, уютнее и камернее внешнего мира.

## Матрица перед выпуском

- RU и KK: свежий путь до конца; RU/KK текст не обрезается.
- Portrait 390×844, landscape, tablet и desktop 1280×720.
- Touch-only: джойстик, прыжок, взаимодействие, пауза, возврат.
- `?quality=low`, `medium`, `high`; на телефоне — прямой renderer без
  обязательного постпроцесса.
- Звук включён/выключен; `prefers-reduced-motion`.
- `npm run type-check`, `npm run lint`, `npm run build`, `git diff --check`.

Фактические FPS, устройства и найденные отклонения записываются в отдельный
worklog того, кто проводил прогон; не считать чек-лист выполненным по одному
скриншоту.
