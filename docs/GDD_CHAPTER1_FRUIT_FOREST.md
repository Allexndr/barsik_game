## 1. Сюжетная арка главы

### Логлайн
Барсик просыпается в своём доме в Фруктовом лесу и обнаруживает, что фрукты перестали расти. Садовник просит его помочь — и Барсик отправляется в путешествие через лес, где знакомится с Айей, находит застрявшие фрукты, встречает загадочного Путало (одинокого фотографа, оставляющего липкие нити), и в финале понимает: Путало не злодей, а просто не умеет дружить. Они становятся друзьями, и лес снова расцветает.

### Тематические столпы
1. **Дружба через помощь** — каждый уровень = помощь кому-то
2. **Исследование через любопытство** — мир приглашает, не заставляет
3. **Уверенность через мастерство** — механика вводится → практикется → комбинируется
4. **Эмпатия к «злодею»** — Путало не враг, а одинокий персонаж

## 2. Дизайн-принципы главы (из книг)

### Level Design (The Level Design Book + Unity Ebook)
- **Critical Path** — каждый уровень имеет один ясный путь от старта до цели
- **Golden Path** — оптимальный маршрут с бонусами (звёзды, фрукты)
- **Signposting** — направление через свет, цвет, указатели, ландмарки
- **Readability** — силуэты и цвета различимы с расстояния; зоны цветокодированы
- **Flow** — плавный переход между зонами без тупиков
- **Metrics** — высота прыжка 1.2м, ширина моста 2.4м, радиус взаимодействия 1.5м
- **Horizon & Skyline** — горы/холмы на фоне для масштаба
- **Affordance** — объекты выглядят так, как с ними можно взаимодействовать

### Game Design (Art of Game Design + Theory of Fun + Game Feel)
- **Rule of Three** — каждая механика: показать → попробовать → повторить
- **Pattern Introduction** — вводить по одной механике за уровень
- **Juice/Feedback** — искры, звук, анимация при каждом действии
- **No Fail State** — для детской аудитории: ошибка = обучение, не наказание
- **Gradual Difficulty** — сложность растёт плавно по кривой

### Narrative Design (Narrative Designer's Playbook)
- **Plan Backward** — каждый уровень начинается с желаемого финала
- **Environmental Storytelling** — мир рассказывает историю через props
- **Character Voice** — каждый NPC имеет уникальный голос и мотивацию
- **Emotional Beats** — чередование спокойствия, напряжения, радости, грусти

## 3. Детальные сценарии уровней

### УРОВЕНЬ 0: «Первое утро» ✅ (существует)
- **Длительность:** 3 мин
- **Механика:** движение (WASD/свайп), взаимодействие (E/тап)
- **Сюжет:** Барсик просыпается, садовник просит собрать фрукты и покормить птичку
- **Финал:** Птичка благодарит, садовник говорит о тропе вглубь леса
- **Награда:** 10 звёзд, друг «Садовник»
- **Связь:** Садовник упоминает, что «глубже в лесу кто-то плачет» → переход к уровню 1

---

### УРОВЕНЬ 1: «Первый друг» ✅ (существует, Mission1Scene)
- **Длительность:** 3–4 мин
- **Механика:** движение, взаимодействие (тяни фрукт 3 раза)
- **Сюжет:** Барсик идёт по тропе, переходит ручей по мостику, находит застрявший в кустах фрукт (с липкими нитями Путало), освобождает его, знакомится со стеснительной Айей, дарит ей фрукт, приглашает в Город Друзей
- **Финал:** Айя соглашается пойти с Барсиком
- **Награда:** 15 звёзд, друг «Айя»
- **Связь:** Айя говорит «Я видела здесь ёжика, он потерялся» → переход к уровню 2
- **Foreshadowing:** Липкие нити — намёк на Путало

---

### УРОВЕНЬ 2: «Яблоневый сад»
- **Длительность:** 3–5 мин
- **Механика:** сбор + сортировка (новая механика: кидай фрукт в правильную корзину)
- **Сюжет:** Барсик и Айя приходят в старый яблоневый сад. Садовник просит помочь рассортировать яблоки по цветам: красные — в красную корзину, жёлтые — в жёлтую, зелёные — в зелёную. Некоторые яблоки на деревьях, некоторые на земле. Айя подсказывает.
- **Зоны:**
  - **Старт:** вход в сад с аркой из яблонь
  - **Центр:** 3 корзины + деревья вокруг
  - **Финал:** садовник благодарит, сад «оживает» (цвета становятся ярче)
- **Level Design:**
  - Критический путь: старт → собрать 6 яблок → разложить по корзинам → финал
  - Золотой путь: собрать 10 яблок (бонусные звёзды)
  - Signposting: корзины подсвечены цветными лучами; деревья с яблоками имеют лёгкое свечение
  - Зона старта: тёплая зелёная
  - Зона корзин: яркая, цветовая кодировка
- **Game Design:**
  - Rule of Three: показать (садовник кидает яблоко в корзину) → попробовать (1 яблоко) → повторить (5 яблок)
  - Ошибка: яблоко падает мимо корзины → можно подобрать и кинуть снова
  - Фидбек: корзина подпрыгивает и издаёт звук при попадании; искры
- **Награда:** 12 звёзд
- **Связь:** Садовник: «Спасибо! А ёжик ваш где-то у старого дуба потерялся» → уровень 3

---

### УРОВЕНЬ 3: «Потерявшийся ёжик»
- **Длительность:** 4–5 мин
- **Механика:** поиск (исследуй зону, найди ёжика по звукам/следам)
- **Сюжет:** Барсик идёт к старому дубу. Лес становится гуще. Нужно найти ёжика, который потерялся. Видны следы на земле (маленькие точки), слышны тихие звуки (визуальные индикаторы — «?» пузыри). Ёжик прячется за камнем/в кустах.
- **Зоны:**
  - **Старт:** поляна у старого дуба (ландмарка)
  - **Зона поиска:** 3 сектора (кусты, камни, поваленное дерево)
  - **Финал:** ёжик найден, обнимает Барсика
- **Level Design:**
  - Критический путь: старт → исследовать 3 сектора → найти ёжика
  - Signposting: следы на земле (маленькие точки-индикаторы), «?» пузыри над секторами
  - Ландмарка: огромный старый дуб в центре — виден из любой точки
  - Verticality: небольшой холм, с которого видна вся зона
- **Game Design:**
  - Механика поиска: подойди к кусту → нажми E → если ёжик там, он выскакивает
  - 2 из 3 секторов — пустые (но содержат бонусы: звёзды, фрукты)
  - 3-й сектор — ёжик
  - Фидбек: при проверке куста — шорох + листья; при находке — искры + радость
- **Награда:** 20 звёзд, друг «Ёжик»
- **Связь:** Ёжик: «Спасибо! Я видел тут качающийся мостик — страшно идти...» → уровень 4

---

### УРОВЕНЬ 4: «Качающийся мостик»
- **Длительность:** 3–4 мин
- **Механика:** timing (новая механика: жди нужный момент, чтобы идти)
- **Сюжет:** Барсик подходит к ущелью с подвесным мостом. Мост качается на ветру. Нужно перейти, двигаясь в моменты, когда мост неподвижен. Если идти когда мост качается — Барсик пошатывается (но не падает — no fail state).
- **Зоны:**
  - **Старт:** край ущелья, вид на мост
  - **Мост:** 5 секций, каждая качается с разным ритмом
  - **Финал:** противоположный край, Айя ждёт
- **Level Design:**
  - Критический путь: старт → пройти 5 секций → финал
  - Signposting: секции моста светятся зелёным когда безопасно, красным когда качается
  - Verticality: ущелье внизу (визуальный контраст, не опасный)
  - Ландмарка: мост — единственный путь через ущелье
- **Game Design:**
  - Rule of Three: первая секция медленная (показать), вторая быстрее (попробовать), 3-5 — комбо
  - Timing: секция качается 2 секунды, спокойна 3 секунды (первая), потом быстрее
  - Ошибка: Барсик пошатывается, остаётся на месте, можно попробовать снова
  - Фидбек: звук скрипа досок, визуальное покачивание
- **Награда:** 15 звёзд
- **Связь:** Айя: «Ты храбрый! Смотри — там кто-то несёт тяжёлую корзину...» → уровень 5

---

### УРОВЕНЬ 5: «Корзина для белочки»
- **Длительность:** 3–4 мин
- **Механика:** эскорт (новая механика: помоги NPC нести предмет)
- **Сюжет:** Барсик встречает белочку, которая несёт тяжёлую корзину с орехами. Она устала. Барсик предлагает помочь. Нужно идти рядом с белочкой, не отставая. По пути есть небольшие препятствия (камни, корни) — нужно обходить их. Если отстать — белочка останавливается и ждёт.
- **Зоны:**
  - **Старт:** поляна с белочкой
  - **Путь:** лесная тропа с препятствиями
  - **Финал:** норка белочки, она дарит жёлудь-ключ
- **Level Design:**
  - Критический путь: старт → идти рядом с белочкой → финал
  - Signposting: белочка оставляет след из орехов (визуальный путь)
  - Flow: плавная тропа без тупиков
  - Ландмарка: норка белочки видна издалека (дерево с дверцей)
- **Game Design:**
  - Эскорт-механика: радиус «рядом» = 3м; если дальше, белочка останавливается
  - Препятствия: 3 камня, 2 корня — нужно обходить
  - Фидбек: сердечки над белочкой когда Барсик рядом; «!» когда отстал
  - Жёлудь-ключ — предмет для уровня 9 (QR-сундук)
- **Награда:** 18 звёзд, друг «Белочка», предмет «Жёлудь-ключ»
- **Связь:** Белочка: «Жёлудь откроет сундук в конце леса!» → уровень 9

---

### УРОВЕНЬ 6: «Лесная загадка»
- **Длительность:** 3–4 мин
- **Механика:** choice (новая механика: выбери правильный ответ)
- **Сюжет:** Барсик выходит на поляну с тремя волшебными деревьями. Старый пенёк задаёт загадку: «Какое дерево любит красные яблоки?» Нужно подойти к правильному дереву и нажать E. Неправильный выбор — дерево качает ветвями (мягкий отказ), правильный — дерево расцветает и роняет звезду.
- **Зоны:**
  - **Старт:** поляна с пеньком-говоруном
  - **Центр:** 3 дерева (красное яблоко, жёлтое яблоко, зелёное яблоко)
  - **Финал:** правильное дерево расцветает
- **Level Design:**
  - Критический путь: старт → послушать загадку → выбрать дерево → финал
  - Signposting: пенёк светится, деревья имеют разные цветовые ауры
  - Ландмарка: пенёк-говорун (лицо на пеньке)
  - Readability: каждое дерево имеет цветовой код (красный/жёлтый/зелёный)
- **Game Design:**
  - 3 загадки, сложность растёт:
    1. «Какое дерево любит красные яблоки?» (прямая)
    2. «На каком дереве сидит птичка с жёлтым хвостом?» (наблюдение)
    3. «Какое дерево самое высокое?» (визуальная оценка)
  - Ошибка: мягкий отказ, можно попробовать снова
  - Фидбек: дерево расцветает, искры, падает звезда
- **Награда:** 16 звёзд
- **Связь:** Пенёк: «А ты умный! Там за поляной кто-то фотографирует...» → уровень 7

### УРОВЕНЬ 7: «Встреча с Путало»
- **Длительность:** 4–5 мин
- **Механика:** explore + dialogue (новая механика: диалог с выбором)
- **Сюжет:** Барсик идёт на поляну и видит странный силуэт — Путало. Вокруг — липкие нити, фотографии на деревьях. Путало фотографирует бабочек, но при виде Барсика прячется за камень. Барсик должен подойти осторожно (медленно!) и заговорить. Путало признаётся, что он одинок, что его «липкие нити» — это его способ отметить красивые моменты, но все их боятся. Диалог: Барсик может сказать «Ты не страшный» или «Зачем нити?» — оба варианта ведут к友善, но разные реплики.
- **Зоны:**
  - **Старт:** вход в тёмную поляну (атмосферная, но не страшная)
  - **Центр:** фотографии на деревьях, нити, камень Путало
  - **Финал:** Путало выходит, они разговаривают
- **Level Design:**
  - Критический путь: старт → подойти медленно → диалог → финал
  - Signposting: фотографии блестят, привлекая внимание; нити — как декор
  - Atmosphere: чуть более тёмное освещение, но тёплое (не хоррор)
  - Ландмарка: огромное дерево с фотографиями
  - Affordance: камень Путало имеет «!» маркер когда близко
- **Game Design:**
  - Механика «медленный подход»: если идти быстро (бег), Путало прячется; если идти шагом — он наблюдает
  - Диалог: 2 выбора, оба позитивные (нет «неправильного» выбора)
  - Фидбек: Путало постепенно выходит из-за камня (анимация)
  - Character moment: Путало показывает свою лучшую фотографию — закат над лесом
- **Награда:** 25 звёзд, друг «Путало»
- **Связь:** Путало: «Я... я могу сфотографировать ваш праздник!» → уровень 8

### УРОВЕНЬ 8: «Лесной праздник»
- **Длительность:** 4–5 мин
- **Механика:** decor/collection (новая механика: размещение предметов + сбор)
- **Сюжет:** Все друзья решают устроить праздник на поляне. Нужно собрать гирлянды (развесить на деревьях), собрать фрукты для стола, и поставить фонарики. Путало фотографирует процесс. Каждый друг помогает по-своему: Айя вешает гирлянды, Ёжик приносит фрукты, Белочка — орехи.
- **Зоны:**
  - **Старт:** поляна для праздника (пустая)
  - **Зона гирлянд:** 3 дерева, на которые нужно повесить гирлянды
  - **Зона фонариков:** 5 точек для фонариков
  - **Зона стола:** собрать фрукты на стол
  - **Финал:** все друзья вокруг стола, Путало делает фото
- **Level Design:**
  - Критический путь: повесить 3 гирлянды → поставить 5 фонариков → собрать 4 фрукта → финал
  - Золотой путь: собрать 8 фруктов (бонус)
  - Signposting: точки размещения светятся; предметы для сбора имеют лучи
  - Ландмарка: большой стол в центре
  - Flow: открытая поляна, можно делать в любом порядке
- **Game Design:**
  - Механика размещения: подойди к точке с предметом → нажми E → предмет размещается
  - 3 типа задач: гирлянды (3), фонарики (5), фрукты (4-8)
  - Фидбек: гирлянда загорается, фонарик светится, искры
  - Финальное фото: все друзья позируют, Путало делает снимок (вспышка)
- **Награда:** 20 звёзд
- **Связь:** Путало: «Какие вы классные! А в конце леса сундук...» → уровень 9

### УРОВЕНЬ 9: «QR-сундук»
- **Длительность:** 3 мин
- **Механика:** puzzle (новая механика: используй предмет из инвентаря)
- **Сюжет:** Барсик и друзья находят сундук в конце леса. На нём замок в форме жёлудя. Белочка говорит: «Мой жёлудь-ключ!» Барсик использует жёлудь (полученный на уровне 5) чтобы открыть сундук. Внутри — звёзды и карта следующей главы (Ледяная долина).
- **Зоны:**
  - **Старт:** поляна с сундуком
  - **Сундук:** в центре, с замком-жёлудем
  - **Финал:** сундук открыт, все друзья радуются
- **Level Design:**
  - Критический путь: старт → подойти к сундуку → использовать жёлудь → финал
  - Signposting: сундук светится золотом; замок имеет форму жёлудя (подсказка)
  - Ландмарка: сундук — единственный объект на поляне
- **Game Design:**
  - Если у игрока нет жёлудя (пропустил уровень 5): Белочка даёт запасной
  - Механика: подойди → нажми E → анимация открытия → искры → награда
  - Фидбек: вспышка, конфетти, звук фанфар
  - QR-элемент: на сундуке QR-код (можно сканировать телефоном для бонуса)
- **Награда:** 30 звёзд, редкий друг «Ягодка»
- **Связь:** Внутри сундука — карта с маршрутом к горам. Айя: «Снег! Я никогда не видела снег!» → переход к Главе 2

### УРОВЕНЬ 10: «Прощание с лесом»
- **Длительность:** 3–4 мин
- **Механика:** explore + farewell (сбор бонусов перед уходом)
- **Сюжет:** Барсик и друзья собираются уходить из Фруктового леса. Садовник прощается, даёт корзину с фруктами на дорогу. Нужно обойти все знакомые места (дом, сад, мостик, поляну) и попрощаться с каждым NPC. На каждом месте — бонусная звезда.
- **Зоны:**
  - **Дом:** попрощаться с садовником
  - **Сад:** собрать последние яблоки
  - **Мостик:** перейти ещё раз (теперь он не качается — знак роста)
  - **Поляна:** попрощаться с пеньком-говоруном
  - **Финал:** выход из леса, дорога к горам
- **Level Design:**
  - Критический путь: 4 точки прощания → выход
  - Золотой путь: собрать все бонусные звёзды (6 шт)
  - Signposting: каждое место имеет «!» маркер; светящиеся следы между ними
  - Ландмарка: дом Барсика (старт и почти-финиш)
  - Flow: круговой маршрут, возвращение к началу
- **Game Design:**
  - Механика: подойди к NPC → нажми E → прощальный диалог → звезда
  - 4 NPC прощаются: садовник, пенёк, ёжик, белочка
  - Фидбек: тёплые искры, мягкая музыка
  - Эмоциональный момент: садовник обнимает Барсика
- **Награда:** 15 звёзд
- **Связь:** Дорога ведёт к заснеженным вершинам → Глава 2

### УРОВЕНЬ 11: «Первые снежинки»
- **Длительность:** 3–4 мин
- **Механика:** timing (ловля снежинок)
- **Сюжет:** Барсик и друзья выходят к подножию гор. Начинается первый снег. Айя никогда не видела снег и радуется. Нужно «поймать» падающие снежинки — подойти к снежинке пока она на земле. Лёгкая медитативная механика.
- **Зоны:**
  - **Старт:** граница леса и снежной зоны
  - **Снежное поле:** открытое пространство с падающими снежинками
  - **Финал:** друзья на снегу, первый снеговик
- **Level Design:**
  - Критический путь: поймать 5 снежинок → финал
  - Золотой путь: поймать 10 снежинок
  - Signposting: снежинки светятся перед падением
  - Ландмарка: первый снеговик (строится по мере ловли)
- **Game Design:**
  - Снежинки появляются случайно, падают 3 секунды, на земле 5 секунд
  - Фидбек: снежинка растворяется с искрами при ловле
  - Атмосфера: тихая, медитативная, мягкая музыка
- **Награда:** 18 звёзд
- **Связь:** Снеговик: «Идите по ледяной тропинке!» → уровень 12

### УРОВЕНЬ 12: «Ледяная тропа»
- **Длительность:** 4–5 мин
- **Механика:** timing + осторожность (скользкая поверхность)
- **Сюжет:** Барсик идёт по узкой ледяной тропе. Скользко — управление становится «инерционным» (Барсик скользит дальше после остановки). Нужно аккуратно пройти, не выскользнув за края. По пути — кристаллы льда (собираемые).
- **Зоны:**
  - **Старт:** вход на ледяную тропу
  - **Тропа:** узкая (2м), с поворотами, 5 сегментов
  - **Финал:** выход на ледяную поляну
- **Level Design:**
  - Критический путь: пройти 5 сегментов → финал
  - Signposting: края тропы подсвечены; кристаллы на пути
  - Verticality: тропа на высоте (визуально, не опасно)
  - Ландмарка: ледяные ворота в конце
- **Game Design:**
  - Физика скольжения: инерция 0.85 (вместо обычной остановки)
  - Ошибка: Барсик выскользнул → возвращается к началу сегмента (no damage)
  - Фидбек: звук скольжения, следы на льду
  - Кристаллы: 6 шт, +2 звезды каждый
- **Награда:** 20 звёзд
- **Связь:** Ледяная поляна — мастер льда ждёт → уровень 13

### УРОВЕНЬ 13: «Ледяные скульптуры»
- **Длительность:** 3–4 мин
- **Механика:** help (помоги мастеру льда)
- **Сюжет:** Мастер льда создаёт скульптуры, но ему не хватает «ледяных осколков». Нужно найти 5 осколков на поляне и принести мастеру. Он создаёт скульптуру Барсика!
- **Зоны:**
  - **Старт:** поляна с мастером льда
  - **Зона поиска:** 5 осколков разбросаны
  - **Мастер:** в центре, у подиума
- **Level Design:**
  - Критический путь: найти 5 осколков → принести → финал
  - Signposting: осколки светятся голубым; следы к мастеру
  - Ландмарка: подиум с незаконченной скульптурой
- **Game Design:**
  - Механика: подбери осколок (E) → отнеси к мастеру (E) → повторить
  - Фидбек: скульптура постепенно появляется (по 1/5 за каждый осколок)
  - Финал: готовая скульптура Барсика, искры
- **Награда:** 16 звёзд, друг «Мастер льда»
- **Связь:** Мастер: «Вам нужен тёплый шарф для друга!» → уровень 14

### УРОВЕНЬ 14: «Поделись теплом»
- **Длительность:** 3–4 мин
- **Механика:** help (найди шарф, отдай другу)
- **Сюжет:** Айе холодно. Нужно найти тёплый шарф (в сугробе) и отдать его Айе. По пути — костёр, у которого можно согреться (механика «согреться» — постоять у костра 3 секунды).
- **Зоны:**
  - **Старт:** зимняя поляна, Айя дрожит
  - **Зона поиска:** сугробы (3 шт, шарф в одном)
  - **Костёр:** точка обогрева
  - **Финал:** Айя в шарфе, улыбается
- **Level Design:**
  - Критический путь: найти шарф → отдать Айе → финал
  - Signposting: сугробы с «?» маркерами; костёр виден издалека
  - Ландмарка: костёр (тёплый свет в холодном мире)
- **Game Design:**
  - Механика «тепло»: шкала тепла убывает; у костра — восстанавливается
  - Если тепло на нуле — Барсик чихает (но не умирает)
  - Фидбек: сердечки над Айей когда получает шарф; тёплые искры
- **Награда:** 22 звёзд
- **Связь:** Айя: «Спасибо! Смотри — снеговик тает!» → уровень 15

### УРОВЕНЬ 15: «Спасти снеговика»
- **Длительность:** 3–4 мин
- **Механика:** help + timing (быстро принеси снег)
- **Сюжет:** Снеговик начал таять (солнце вышло из-за туч). Нужно быстро принести 3 куска снега из сугробов и положить на снеговика. Таймер — но мягкий: если не успел, снеговик просто становится меньше, можно попробовать снова.
- **Зоны:**
  - **Старт:** поляна с тающим снеговиком
  - **Сугробы:** 3 точки со снегом
  - **Снеговик:** в центре
- **Level Design:**
  - Критический путь: принести 3 куска снега → финал
  - Signposting: сугробы светятся; снеговик мигает
  - Ландмарка: снеговик (меняет размер — визуальный прогресс)
- **Game Design:**
  - Механика: подбери снег → отнеси к снеговику → повторить 3 раза
  - Таймер: 30 секунд на каждый кусок (мягкий)
  - Фидбек: снеговик растёт обратно; искры; радость
- **Награда:** 20 звёзд, друг «Снеговик»
- **Связь:** Снеговик: «Спасибо! А вон там фонарики погасли...» → уровень 16

## 4. Техническая архитектура

### Базовый класс `BaseLevelScene`

Общая функциональность для всех 3D-уровней:
- Renderer, camera, lighting setup
- Input (keyboard + joystick)
- Player character loading + animation
- Collision system (AABB + circle)
- HUD callback system
- Phase machine
- Spark/particle effects
- Guide arrow
- Path arrows
- Disposal/cleanup

### Структура уровня

```typescript
abstract class BaseLevelScene {
  // Shared infrastructure
  protected renderer, scene, camera, clock
  protected hero, mixer, walkAction, idleAction
  protected keys, joy
  protected colliders: Collider[]
  protected sparks: THREE.Mesh[]
  protected clouds: THREE.Group[]
  protected guideArrow
  
  // Shared methods
  protected abstract init(): Promise<void>
  protected abstract pushHud(): void
  protected abstract loop(): void
  
  // Shared utilities
  protected loadHero(loader)
  protected loadTrees(loader, count, positions)
  protected setupLighting(fogColor, sunColor)
  protected setupGround(texture, size)
  protected setupSkyDome()
  protected addPathArrows(positions)
  protected addZoneDiscs(zones)
  protected spawnSparks(at, count)
  protected resolveCollisions(nx, nz)
  protected updateCamera(target, look, lerp)
  protected bindKeys()
  protected resize()
  dispose()
}
```

### Уровень → UI маппинг

```
Level 0  → Mission0Screen (existing)
Level 1  → Mission1Screen (new, wraps Mission1Scene)
Level 2+ → MissionScreen (generic, wraps any BaseLevelScene)
```

### Интеграция в useUIStore

```typescript
startEpisode: (episodeId) => {
  if (episodeId === 0) → 'mission0'
  if (episodeId === 1) → 'mission1'  
  if (episodeId >= 2 && episodeId <= 16) → 'mission' (generic)
  else → 'episode' (timer stub for chapters 2-6)
}
```

## 7. Нарративная структура (Narrative Designer's Playbook)

### Arc 1A: Фруктовый лес (уровни 0–9)
**Тема:** Знакомство с миром, первые друзья
**Эмоциональная цель:** Игрок чувствует себя нужным и welcomes
**Структура:**
- Setup (0–1): Мир, механика, первый друг
- Rising Action (2–6): Помощь, исследование, новые механики
- Turning Point (7): Встреча с «антагонистом» Путало
- Resolution (8–9): Праздник, сундук, завершение

### Arc 1B: Переход (уровни 10–16)
**Тема:** Переход из тепла в холод, новые вызовы
**Эмоциональная цель:** Игрок чувствует рост и уверенность
**Структура:**
- Farewell (10): Прощание с лесом
- Discovery (11–12): Снег, лёд, новые механики
- Helping (13–15): Новые друзья в зимнем мире
- Climax (16): Финальный сундук, переход к Главе 3
