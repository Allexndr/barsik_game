# GAME-BASELINE — «Путешествие Барсика» (Season 1)

**Дата:** 2026-09-04 · **Метод:** чтение кода + запуск и реальное прохождение.
**Объём:** ~41 900 строк TS/TSX · 506 МБ ассетов · 718 озвученных реплик · 17 уровней.
**Стек:** Vite + React 18 + TypeScript + императивный Three.js + Zustand + Supabase.

---

## 1. Жанр и core loop

**Жанр:** детское 3D-приключение от третьего лица (soft-3D plush), браузер, RU/KK.
**Аудитория:** заявлена противоречиво — `product-state.md` говорит 3–7, `CLAUDE.md` — 5–12,
а фактические тестировщики от заказчика — **10–14**. См. риск UX-1.
**Принцип канона:** *no fail state* — проигрыша нет нигде. Ошибка = «попробуй ещё».

```
Карта путешествия
      │  клик по разблокированному пину
      ▼
Экран загрузки (мини-игра «прыгай через препятствия») → «Играть»
      ▼
3D-уровень: диалог NPC → цель в HUD → фазы уровня → стрелка-подсказка ведёт к цели
      ▼
outro: звёзды + иногда новый друг
      ▼
«Продолжить путешествие» → карта, следующий пин открыт
      ▼
мета: Друзья · Город (Арбат-хаб) · Магазин · Рейтинг · QR-сундук
```

Вторичный цикл: звёзды → гардероб/украшения. Третичный: QR-сундук (L9, L16) → упаковка.

## 4. Игровые системы

1. **Движение** — `BaseLevelScene.updateMovement`. Гравитация 12.2, прыжок 5.4, шаг 3.2, бег 4.4.
   Бег включается Shift **или отклонением стика > 0.75** — порог невидим для игрока.
2. **Ограничение зоны** — три слоя: жёсткий clamp x/z → коридор `pathCorridor ± half` + комнаты
   `reserve()` → коллайдеры. Границы по z выводятся из комнат в `encloseLevel()` — **источник блокера L5**.
3. **Коллизии** — `resolveCollisions()`: AABB (выталкивание по меньшей оси) + окружности.
4. **Платформы** — `addPlatform()` + `standHeightAt()`, читают позицию живьём.
5. **Фазовый автомат** — у каждого уровня свой `Phase`-union. Единственный источник победы: `phase === 'outro'`.
6. **Награды** — `completeLevel()` берёт `max(previousBest, reward)` → двойных начислений нет.
7. **Сохранение** — синхронная запись в localStorage на каждое изменение, версия 2.
8. **Аудио** — музыка на уровень, 15 SFX, TTS с озвученным паком.
9. **Качество** — 3 тира, отдельные ветки для mobile.
10. **Локализация** — `t()` + inline двуязычные строки в сценах (два механизма).
11. **Soft-gates** — сбор телефона/e-mail с пропуском.
12. **Сеть** — Supabase Realtime для хаба; модерация текста на отправке и приёме.
13. **Dev-аудит** — `window.__audit()`: недостижимые объекты, пропсы под землёй, чёрные меши, потеря героя камерой.

## 6. Технические риски

| ID | Риск | Обоснование |
|---|---|---|
| TR-1 | **Границы зоны выводятся из `reserve()`** | уровень, забывший зарезервировать старт, ломается молча — это и есть L5. Инварианта нет |
| TR-2 | **Кадрозависимая физика** | `velocity *= inertia` на кадр (L12): чем выше FPS, тем медленнее герой |
| TR-3 | `BaseLevelScene` — god-object | 3700+ строк: рендер, физика, камера, ввод, аудио, растительность, качество |
| TR-4 | 17 почти-дублей `MissionNScreen` | `startEpisode` — 17 копипаст-веток `if (episodeId === N)` |
| TR-5 | **506 МБ ассетов** в `public/` | без CDN и разбиения по главам — тяжёлый вход на мобильном интернете KZ |
| TR-6 | Секреты в `.env` рядом с репо | OPENAI / MESHY / HF / TOGETHER / VERCEL |
| TR-7 | localStorage — единственное хранилище | другое устройство или очистка кэша = потеря сезона |
| TR-8 | Четыре режима героя | `rigged / static / plush / avatar` — тестируется, вероятно, один |
| TR-9 | Два механизма i18n | `t()` + inline тернарники в сценах |
| TR-10 | ~~Утечки WebGL~~ | **проверено — утечек нет** (12 переходов подряд) |
| TR-11 | ~~Нет ErrorBoundary~~ | **закрыт** — `AppErrorBoundary.tsx` добавлен |
| TR-12 | Нет обработки потери WebGL-контекста | нет `webglcontextlost` — на слабом мобильном это чёрный экран |

## 11. Верификация 2026-08-30

### Подтверждено

- Welcome desktop/mobile, hub и L0–L16: HTTP 200; canvas присутствует на уровнях.
- 25/25 Playwright tests passed in one worker (Chromium: 17 level boots + replay + keyboard
  map pin + restart + pause/accessibility + language switch + hidden-tab; mobile: 1 smoke);
  RU/KK L1 launch passed.
- L0/L1/L4 desktop и L8/L15 mobile: «Играть», движение, pause → «Продолжить»; без console/page/request errors.
- Regression tests: повреждённый save не объявляет сезон завершённым; после финала карта даёт replay CTA; playable pins работают с клавиатуры; progression/admin integration contracts pass.

### Не подтверждено и не должно считаться пройденным

- Честное прохождение всех фаз до `outro`, UI save/load в каждой фазе, реальные устройства,
  звук на слух и offline/realtime сценарии.
- `window.__audit({ grid: 5 })` не завершён в разумный timeout: это дорогой dev-инструмент,
  а не доказательство отсутствия soft-lock.

### Изменения после baseline

- ErrorBoundary/init recovery, прогресс-контракт Supabase, admin identity/rate-limit подготовка,
  Playwright/Vitest harness и исправления corrupt-save/replay/keyboard-map были добавлены после
  исходного снимка. Полный список решений — в `MASTER-ROADMAP.md`.
