# UX-AUDIT — «Путешествие Барсика» Season 1

**Дата:** 2026-09-04 · Проверено в браузере: 1280×720, 375×812, 768×1024, RU + KK.
Источники: живое прохождение, отзывы детей 10–14, код UI.

---

## 1. Первый вход

| Шаг | Состояние | Проблема |
|---|---|---|
| Лендинг | ✅ чистый, кнопка «Играть» заметна | — |
| Ник + пол | ⚠️ | «Мальчик»/«Девочка» — один SVG-облик 52 px, отличие только бантик. На телефоне неразличимы |
| Валидация ника | 🔴 | «Имя слишком короткое» — мелкий красный текст без иконки и озвучки. Для нечитающего ребёнка это **тупик на первом экране** |
| Экран загрузки | ✅ | Мини-игра «прыгай через препятствия» — отличное решение против ожидания |
| Кнопка «Играть» на загрузке | ⚠️ | Анимируется непрерывно и не приходит в покой (Playwright: `element is not stable` 22 попытки за 30 с). Не уважает `prefers-reduced-motion` |
| Возраст | ⚠️ | Не спрашивается, хотя `ageCategory` есть в модели — а от возраста зависит вся сложность |

## 2. Управление

| Элемент | Состояние |
|---|---|
| Плавающий джойстик (встаёт под палец в левой половине) | ✅ хорошее решение, снимает главную жалобу на мобильное управление |
| WASD / стрелки | ✅ |
| `E` / `Space` — действие, `Space` — прыжок | ✅ |
| Орбита камеры (тянуть) | ✅ есть, подсказка `CameraLookHint` показывается |
| **Вертикальный наклон камеры** | 🔴 **отсутствует** — прямой запрос тестировщиков «надо смотреть сверху вниз» |
| **Бег** | 🔴 невидимый порог: отклонение стика > 0.75 = бег. На этом держится весь L7, но игра об этом не говорит ни разу |
| coyote-time 190 мс, jump-buffer 220 мс | ✅ прощает две настоящие детские ошибки |

**Главная проблема управления — не оно само, а задержка:** на 13 из 17 уровней ввод
не работает 4.7–7.8 с после нажатия «Играть», при том что HUD уже пишет «Двигайся».
Проверено: удержание `W` 1.5 с в фазе `intro` даёт смещение **0 м**.
Для ребёнка это читается как «игра сломана».

## 4. Победа, поражение, рестарт

| Что | Состояние |
|---|---|
| Победа | ✅ карточка outro со звёздами и другом |
| Поражение | ⛔ **нет по канону** — осознанное решение для детской аудитории |
| **Рестарт уровня** | 🔴 **отсутствует полностью** — ни в HUD, ни в паузе, ни на outro |
| Выход из уровня | 🔴 «Выйти на карту →» без подтверждения, **звёзды уровня теряются молча** |
| **Пауза** | 🔴 открывает громкость/язык/TTS вместо «Продолжить / Заново / Выйти» |

Это самая дорогая связка проблем: любой застрявший ребёнок обязан выйти и потерять прогресс,
и не может просто попробовать ещё раз. Прямо противоречит канону «Ошибка — обучение:
попробуй ещё» (`CLAUDE.md`).

## 10. Приоритеты UX

### 🟥 Blocker
- UX-1. **L5 непроходим** — первое движение уносит на 70 м (детали в `BUG-REPORT.md`).

### 🟧 Critical
- UX-2. Телефон спрашивают у ребёнка на первом кадре, без родительского барьера.
- UX-3. Нет рестарта; выход стирает звёзды молча.
- UX-4. Управление мертво 4.7–7.8 с, пока HUD требует идти.
- UX-5. Стрелка-подсказка врёт (L0, L3).

### 🟨 High
- UX-6. Пауза ведёт в настройки вместо игрового меню.
- UX-7. После финала сезона на десктопе играть нечем.
- UX-8. Бег — невидимый порог стика 0.75, на нём держится L7.
- UX-9. Пины карты недоступны с клавиатуры и для скринридера.

### 🟩 Medium
- UX-10. Нет вертикального наклона камеры (прямой запрос тестировщиков).
- UX-11. Ошибка ввода ника — мелкий текст без озвучки.
- UX-12. «Мальчик»/«Девочка» неразличимы.
- UX-13. Возраст не спрашивается, хотя от него зависит сложность.

### ⬜ Polish
- UX-14. Кнопка «Играть» на загрузке анимируется без остановки.
- UX-15. Одинаковая похвала и одинаковая реакция на ошибку.
- UX-16. L0 работает только со звуком.
