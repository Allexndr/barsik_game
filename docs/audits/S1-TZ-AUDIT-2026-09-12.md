# Сверка ТЗ Season 1 и аудит сложности

**Дата:** 12.09.2026 · **Основание:** `docs/S1_REMAINING_SPEC.md`, `docs/S1_ACCEPTANCE.md`,
`docs/audits/RELEASE-READINESS.md`, локальный код и повторный QA-прогон.

## Итог

Локальная версия сезона технически проходит стартовую проверку всех 17 уровней: **17/17**
в четырёх последовательных блоках без QA-ошибок. Предыдущие остановки на L0 и L1 оказались
ошибкой направления тестового стика, а не soft-lock. Для детей исправлены четыре заметные
точки непонимания: видимая цель L0, счётчик секторов L3, окна безопасности L4 и выбор корзины L2.

Это не заменяет приёмочный golden path на настоящем телефоне и не закрывает внешние серверные
гейты. Поэтому статус сезона: **готов к повторной демонстрации локально, release-ready ещё не подтверждён**.

## Аудит трудности L0–L16

| Уровень | Оценка для ребёнка | Решение / остаток |
|---|---|---|
| L0 | лёгкий после фикса | маяк на юрту виден сразу; 11 камней, самый сложный разрыв имеет запас; проверить на телефоне |
| L1 | лёгкий–средний | мост и фрукты достижимы; нужен portrait smoke именно на реальном экране |
| L2 | средний, но понятный после подсказки | шесть яблок допустимы по ТЗ; правильная корзина теперь ярче остальных, ошибка не отнимает яблоко |
| L3 | средний | пять коротких секторов вместо длинного зигзага; HUD теперь показывает фактическое число 5 |
| L4 | средний | окна безопасного прохода расширены, ускорение нарастания смягчено; 5/5 секций проходят |
| L5 | средний | маршрут и перенос исправлены, полный прогон 77 с; наблюдать отставание от белки на телефоне |
| L6 | средний по механике, высокий по чтению | решатель проходит 166 с; детям нужна проверка озвучки и длины текста загадок, код не упрощать без наблюдения |
| L7 | средний–сложный | бег обозначен на стике и есть раннее предупреждение; проверить, понимают ли дети «иди медленно» |
| L8 | лёгкий–средний | сбор сокращён до 3 фруктов и около 20 с; финальный кадр читаемый |
| L9 | средний | ягоды и кодовый замок требуют внимательности; последовательность должна быть проверена человеком |
| L10 | средний | один обход вместо челнока 216 м; финальная точка остаётся боковым ответвлением |
| L11 | средний | проверка запуска проходит; поймать 2 снежинки нужно замерить человеком |
| L12 | средний | скорость и подбор кристаллов исправлены; на телефоне проверить скольжение и торможение |
| L13 | лёгкий–средний | пять осколков сближены до 57 м маршрута; разнообразие объектов остаётся улучшением |
| L14 | средний | шкала тепла и цели читаемы; проверить темп на слабом устройстве |
| L15 | средний–сложный из-за таймера | предметы сближены, цикл около 80 с; нужен детский тест таймера, а не дальнейшее автоматическое упрощение |
| L16 | лёгкий финал | друзья сведены в видимую поляну, сундук и награда читаемы; нужен тест replay CTA после сезона |

## Что осталось по ТЗ

**До локальной приёмки:**

- пройти L0→L16 человеком с обычной клавиатурой и телефоном, включая награду, карту и reload;
- проверить L1/L8/L16 в portrait 390×844 и L0/L1 в landscape;
- отдельно проверить L6 (три загадки), L7 (бег/медленно), L11 (ловля) и L15 (таймер) детьми целевой группы;
- подтвердить отсутствие чёрного кадра KBTU и проверить ambient-модели на реальном устройстве.

**Вне текущего кода:**

- deploy актуального `main` на Vercel и production smoke;
- native KK proofread с повторной озвучкой изменённых строк;
- решение по cloud save, leaderboard write и Supabase RLS/realtime;
- финальный брендовый rig Барсика и реальные QR-награды от заказчика.
