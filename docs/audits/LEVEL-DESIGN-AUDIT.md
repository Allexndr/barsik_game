# LEVEL-DESIGN-AUDIT — Season 1

**Дата:** 2026-09-04 · Источники: код сцен, `docs/GDD_CHAPTER1_FRUIT_FOREST.md`,
`utils/levels.ts`, живое прохождение (`PLAYTEST-REPORT.md`), отзывы детей 10–14.

Для каждого уровня: **чему учит · механика · цель · начало → напряжение → кульминация →
награда · эмоция · читаемость маршрута · слабые места · где запутается · что сделать**.

> В интерфейсе уровни подписаны как «Уровень N+1». Ниже — код-`id` и подпись в UI.

---

## Сквозные наблюдения

1. **Начало съедено задержкой.** На 13 из 17 уровней управление мертво 4.7–7.8 с, а HUD уже
   говорит «Двигайся». Первая эмоция каждого уровня — не любопытство, а «не работает».
2. **Кульминация часто отсутствует.** У большинства уровней структура «делай N раз → готово»,
   без нарастания. Исключения с настоящей кульминацией: L0 (юрта), L7 (доверие Путало),
   L15 (снеговик тает), L16 (финал).
3. **Маршрут читается хорошо там, где есть коридор**, и плохо там, где цели разбросаны по
   площади (L3 — 26–36 м между секторами).
4. **Награда одинаковая** независимо от качества игры — нет причины стараться.

## Мир 1 — «Фруктовый лес»

### L0 · UI «Уровень 1» · Первое утро / Тропа домбры
- **Чему учит:** двигаться, взаимодействовать, прыгать.
- **Механика:** explore + навигация по звуку домбры.
- **Цель:** дойти на звук, зажечь 3 фонаря, перейти реку, починить юрту, повторить наигрыш.
- **Структура:** начало — пробуждение и звук; напряжение — переправа по камням;
  кульминация — юрта и игра «эхо»; награда — Садовник, 10★. **Структура полная — лучший уровень сезона.**
- **Эмоция:** любопытство → лёгкая тревога на воде → тепло внутри юрты. Задумано верно.
- **Читаемость:** высокая — коридор, звук как компас, фонари как вехи.
- **Слабые места:**
  - 🔴 переправа требует разбега, а бега в уровне нет (последний прыжок 3.53 м при 2.83 м);
  - падение сбрасывает **все** камни — цена ошибки непропорциональна;
  - стрелка всю переправу указывает на первый камень;
  - навигация только по звуку — при mute ориентир исчезает;
  - название расходится: на карте «Первое утро», в игре «Тропа домбры».
- **Где запутается:** на воде. Это первый уровень — там нельзя терять игрока.
- **Что сделать:** сократить последний прыжок до ≤ 2.4 м; не сбрасывать все камни;
  стрелку — на следующий камень; продублировать звук визуально; свести названия.

### L2 · UI «Уровень 3» · Яблоневый сад
- **Чему учит:** сортировать по признаку.
- **Механика:** help/sort. **Цель:** 6 яблок по цветам, открыть арык, расчистить, отнести подарок.
- **Структура:** demo → collect → sort → aryk → clear → gift → deliver. **Семь битов — больше всех.**
- **Эмоция:** спокойная работа. Кульминации нет — просто больше того же.
- **Читаемость:** высокая (корзины цветокодированы).
- **Слабые места:** дети сказали «интересный, но непонятно что делать» — при том, что уровень
  технически исправен (82 с). Значит проблема в **подаче цели**, а не в механике.
  Семь битов подряд без нарастания — длинно.
- **Где запутается:** на переходе `collect → sort`: неясно, что яблоко надо нести к корзине.
- **Что сделать:** усилить демонстрацию (садовник кидает яблоко **при игроке**, а не в интро);
  подсветить корзину нужного цвета в момент, когда яблоко в лапах; сократить до 4–5 битов.

### L3 · UI «Уровень 4» · Потерявшийся ёжик
- **Чему учит:** искать по следам.
- **Механика:** find — **единственный раз за сезон**.
- **Цель:** проверить 5 секторов, найти ёжика.
- **Структура:** есть только «повтори 5 раз». Кульминация — находка.
- **Эмоция:** задумано «любопытство», получается «долго».
- **Читаемость:** 🔴 **низкая.** Сектора: (−17,−6) → (18,−14) → (−14,−22) → (12,−29) → (−3,−33).
  Между соседними **26–36 м**, суммарно ≈111 м, между ними пусто. Маркер цели уходит
  на 2.2 м под землю.
- **Слабые места:** это марш, а не поиск. Дети назвали уровень «слишком тяжёлым» — и это
  честно: 35 с чистой ходьбы без событий.
- **Где запутается:** после 2-го сектора — непонятно, зачем идти через всю карту.
- **Что сделать:** сжать зигзаг до 12–18 м; положить след/бонус между секторами;
  поднять маркер на землю; переиспользовать `find` ещё на 1–2 уровнях, чтобы механика окупилась.

### L7 · UI «Уровень 8» · Встреча с Путало
- **Чему учит:** осторожности и эмпатии.

- **Структура:** approach → slow → hiding → dialogue. **Настоящая кульминация — Путало
  показывает фотографию.** Лучший нарративный уровень сезона.
- **Эмоция:** осторожность → нежность. Задумано и работает.
- **Читаемость:** хорошая — шкала доверия видна.
- **Слабые места:** 🔴 **весь уровень держится на невидимом пороге** — стик > 0.75 считается
  бегом и пугает Путало. Проверено: со стиком 1.0 уровень непроходим (бесконечный
  `slow↔hiding`), со стиком 0.6 идёт нормально. Игра учит «замри, когда смотрит», но
  **никогда не говорит «иди медленно»**.
- **Где запутается:** ребёнок держит стик до упора — это естественный жест — и не понимает,
  почему его прогоняют.
- **Что сделать:** индикатор скорости у джойстика; явная реплика «отпусти стик наполовину»;
