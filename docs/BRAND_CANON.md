## Друзья на brand-листе (trio)

Те же пропорции ирбиса; разные outfits (современный streetwear + казахский орнамент):

1. **Cool Barsik** — худи / джинсы / тюбетейка / жёлтые очки (герой)  
2. **Explorer** — полосатый свитер, орнамент-шарф, круглые очки, камера, сандық  
3. **Musician** — фиолетовое платье, розовые очки, диадема, домбра  

В S1 сюжетные друзья (Ая, Путало, Жулдыз…) остаются; визуально тянуть к soft-toy + казахским акцентам из trio.
