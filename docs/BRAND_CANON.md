## Барсик (герой)

Снежный барс-ирбис, chibi **плюшевый**: большая голова, белый мех, **чёткие розетки-пятна**, розовый нос, большие глаза, пушистый хвост. Эмоция — радость (слоган «Барсик поймай радость»), не грусть.

**2D упаковка / фото ≠ 3D в игре** — отличия нормальны и ожидаемы. Канон по силуэту/цветам/аксам берём с фото; мимику, пропорции-плюш и «живость» доводим **качественно в игровом 3D**, а не копируем пиксель-в-пиксель 2D.

### База (без одежды)

Меховое тело с пятнистостью барса. Одежда/аксы — только wardrobe (худи, тюбетейка, очки, будущие костюмы: космонавт / полиция / врач / строитель).

### Полные Meshy-образы (смена целого GLB)

Meshy не даёт слойный гардероб на один скелет → образы = отдельные `*_rigged.glb` (Idle/Walk/Wave):

| look | файл | URL |
|------|------|-----|
| cool | `barsik_cool_rigged.glb` | `?look=cool` |
| explorer | `barsik_explorer_rigged.glb` | `?look=explorer` |
| musician | `barsik_musician_rigged.glb` | `?look=musician` |
| nude | `barsik_nude_rigged.glb` | `?look=nude` |
| cap / scarf | `barsik_cap_rigged` / `barsik_scarf_rigged` | `?look=cap` / `?look=scarf` |

Стартовый Meshy-герой: `barsik_cool_rigged` / `barsik_rigged` (зелёное худи как 2D). Одежда **вшита** в GLB — не wardrobe поверх. `barsik_pack` (красный) — эксперимент, не дефолт. База без одежды: `?look=nude`. Procedural wardrobe: только `?hero=avatar`.

Те же пропорции ирбиса; разные outfits (современный streetwear + казахский орнамент):

В S1 сюжетные друзья (Ая, Путало, Жулдыз…) остаются; визуально тянуть к soft-toy + казахским акцентам из trio.

## Правило выбора модели

При любом выборе GLB / генерации / swap:

1. Сначала сверь с `photos/`
2. Для героя в игре — **procedural avatar** (мех + wardrobe body/аксы)
3. Полные одетые образы — Meshy `*_rigged.glb` через `?look=`
4. Друзья/NPC — `loadCharModel` предпочитает `name_rigged.glb`
5. Гардероб по умолчанию = trio cool Barsik (худи+джинсы+тюбетейка+очки)
