1. Какой scope считать «первым сезоном»

Важно, чтобы не было спора «где 100 уровней».
Ранний документ «ТЕХНИЧЕСКОЕ ЗАДАНИЕ Путешествие БАРСИКА» описывал продуктовую экосистему (100 уровней, 6 миров, push, реальные призы). Рабочий канон производства, зафиксированный в SEASON_1_FULL_SPEC.md (30.07.2026) и подтверждённый ходом работ: Season 1 = 17 уровней (0–16) в 2 мирах + мета (карта, друзья, хаб, shop, QR-demo, RU/KK). Старые количественные рамки в FULL_SPEC явно помечены как устаревшие (§2 «Не использовать»).

Этот пакет закрывает фактически выполненную часть согласованного S1, а не фантазийный полный CRM на 100 уровней и не «идеальный AAA soft-3D».

4. Что ответить по сумме (рамка)

A. Работа: [СУММА_A] ₸ = согласованная цена этапа S1 × 65–75% − авансы.
Обоснование доли: playable soft-launch и материалы передаются; premium/device/cloud/KK-native не закрыты.

B. Расходы (только по чекам):

  • Meshy 3D — да, был расход; в логе ≥1210 кредитов на зафиксированных батчах; на диске большой набор GLB. Сумма = по инвойсам.
  • ElevenLabs — 0 (не покупали; Edge TTS).
  • Vercel/домен — обычно сторона заказчика; включать только если платил исполнитель.
  • Cursor/GPT — ориентир из интервью ~50 тыс. ₸, только если письменно договорились.

ИТОГО = A + B − авансы. Пока чеки/договорная сумма не подставлены — итоговую цифру нельзя выдавать как факт. См. Excel лист 00_ИТОГО и 08_Черновик_ответа.

Из интервью 16.07 (память, не договор): ориентир оплаты «~150», инструменты ~50 тыс. ₸, сервер заказчика ~20 тыс. ₸/мес — единицу «150» уточнить.

Требование ТЗ

Браузерная игра, лендинг, CTA «Играть», RU/KK переключатель, без рекламы.

По факту

E07 ЧАСТИЧНО §10 Audio / TTS
15_guide_arrow_alt_2026-08-31.png

Требование ТЗ

Музыка миров, SFX, TTS RU+KK на ключевых репликах.

По факту

Procedural music/SFX + Edge neural packs: manifest 712 линий, ~1428 mp3 на диске; prod manifest HTTP 200.

Почему считаем доказанным

Озвучка подготовлена как контент (не «пустая папка»). Это материальный deliverable.

Честный пробел

На части устройств autoplay блокирует HTMLAudio до жеста; пользователь сообщал «озвучка не работает». Баг UX, не отсутствие ассетов.

E08 ВЫПОЛНЕНО §11 Art / 3D assets
06_gameplay_archive.png

Требование ТЗ

Герой и друзья 3D; soft-3D plush style lock.

По факту

На диске десятки Meshy/Hyper3D/CC0 GLB: chars≈59, props≈79, hub≈20. Каст друзей wired.

Закупка/генерация моделей — отдельная статья расходов и отдельный результат передачи.

Честный пробел

Не все модели «идеальный бренд»; часть в quarantine; финальный bone-rig — EXT.

  1. Git-репозиторий + архив рабочего дерева (если есть незакоммиченное).
  2. Prod URL + доступ Vercel (по согласованию).
  3. Архив public/assets/models + public/assets/voice.
  4. Документы: FULL_SPEC, S1_READINESS, GDD, ADMIN, этот settlement-пакет.
  5. Supabase project ownership transfer.
