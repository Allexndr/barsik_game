## Риски

### 1. `vercel.json`: кэш `/assets/` понижен с года до суток для ВСЕХ ассетов
`Cache-Control` для `/assets/(.*)` изменён с
`public, max-age=31536000, immutable` на `public, max-age=86400, must-revalidate`.

Судя по диффу в `WelcomeScreen.tsx`/`TravelMapScreen.tsx`, цель — сбросить кэш
для трёх картинок лендинга/карты (добавлен `?v=20260814`). Но заголовок в
`vercel.json` общий на весь префикс `/assets/`, включая тяжёлые GLB-модели и
текстуры трёх уровней и хаба — то, что в `CLAUDE.md` уже отмечено как
источник боли (гигабайтный деплой). `?v=` уже решает инвалидацию для
конкретных файлов; понижение TTL для всего `/assets/` — лишний побочный
эффект, который увеличит ревалидационный трафик на каждой загрузке уровня.

**Рекомендация:** вернуть `/assets/` на `immutable, max-age=31536000` и
полагаться на `?v=` для точечного сброса конкретных картинок, либо явно
подтвердить, что общее понижение TTL — осознанное решение.

### 2. `arbatProps.ts`: новые стили фасадов (`flat`, `attic`) нигде не вызываются
`buildFacade` получил параметры `style: FacadeStyle = 'classic'` и `seed = 0`
с большим блоком геометрии под `flat`/`attic` (мансарды, люкарны, балконы,
эркер). Все три вызова в `src/three/scenes/hub/places.ts:110,119,235`
по-прежнему передают старую сигнатуру без `style`/`seed` — из-за дефолтов
компилируется, но **улица Арбат продолжит рендериться только `classic`**.
Комментарий в коде утверждает обратное («три архитектурных языка» вместо
«одного шаблона под разными цветами»), а по факту ничего не изменилось
визуально: `trimTint(seed=0)` тоже всегда даёт одно и то же смещение оттенка.

Не баг компиляции, но незавершённая фича: код добавлен, но не подключён.

**Рекомендация:** либо прокинуть `style`/`seed` в вызовы `buildFacade` в
`places.ts` (например, чередовать `['classic','flat','attic']` по индексу
дома `i`, `seed = i`), либо, если это намеренно отложено, явно пометить
TODO в `places.ts` рядом с вызовами.

## Подтверждено корректным

- **`Mission1Scene.ts`**: `placeMany` → `this.placeProps(loader, [...])` —
  приводит код в соответствие с правилом `CLAUDE.md` («не звать `placeMany`
  напрямую»); раньше ягоды/грибы в этой сцене ставились без коллайдера.
- **`.vercelignore`**: пути заанкорены (`assets/` → `/assets/`, аналогично
  `tools/`, `.venv-bg/`, `vendor/`). Старые неанкорированные паттерны в
  gitignore-семантике совпадают с директорией `assets` **на любом уровне**,
  включая `public/assets/` (рантайм-ассеты, которые обслуживает сайт) — то
  есть теоретически рисковали случайно попасть под игнор при упаковке для
  Vercel. Анкоринг с `/` фиксирует это на уровне корня репозитория и
  является улучшением, а не риском.
- Типы — `npx tsc --noEmit` без ошибок.
