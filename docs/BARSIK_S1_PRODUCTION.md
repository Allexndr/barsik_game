## 1. Дизайн-столпы Сезона 1 (из книг → в код)

Извлечено из *The Level Design Book*, *Unity Intro to Level Design*,
*Designing Games for Children*, *The Narrative Designer's Playbook*.

1. **Дружба через помощь.** Каждый уровень = помочь кому-то. (narrative anchor)
2. **Приглашение, не принуждение.** Мир зовёт любопытством; нет fail-state, нет
   наказания — ошибка это обучение. (children UX)
3. **Мастерство через правило трёх.** Каждая механика: показать → дать попробовать
   → повторить/усложнить. Одна новая механика за уровень. (Unity LD, Koster)
4. **Игрок становится лучше, чем персонаж.** Радость и фэнтези важнее драмы;
   якорь — «ты нужен, ты добрый, ты справился». (Narrative Playbook)

Каждый маленький beat уровня обязан работать на один из этих столпов.

## 2. ПЛАНКА ПРЕМИУМА — чек-лист приёмки уровня

Уровень считается «done to premium» только когда проходит ВСЕ пункты.
Это контракт: раскатываем флагман → каждый следующий уровень проходит тот же лист.

### A. 3C — Camera, Character, Control
- [ ] **Character:** герой = процедурный Барсик (не лиса-плейсхолдер), с idle/walk,
      узнаваемый силуэт (худи, очки, хвост барса) под style-lock.
- [ ] **Camera:** плавный follow (lerp), никогда не клиппит сквозь геометрию,
      кинематографичный intro-заезд, работает в портрете и ландшафте.
- [ ] **Control:** WASD + стрелки + мобильный джойстик; отзывчиво (<100мс),
      поворот героя в сторону движения, бег по shift/дальнему стику.

### B. Геймплей ≥ 5 минут, читаемый
- [ ] Одна ясная **новая механика**, введённая по правилу трёх.
- [ ] **Critical path** нельзя потерять; **golden path** (бонусы) визуально ОТЛИЧЕН
      от основного (напр. золотые кольца vs белые).
- [ ] **Pacing:** чередование действие/отдых; минимум 3 gameplay-beat.
- [ ] Хронометраж честно 4–6 мин на первом прохождении (замер плейтестом).
- [ ] Нет **soft-lock** и нет тупиков; есть мягкий чекпоинт/повтор сегмента.

### C. Signposting & средовое повествование
- [ ] Направление через свет / цвет / указатели / ландмарку — не только текст.
- [ ] Зоны цвето-кодированы, силуэты читаемы издалека.
- [ ] Мир рассказывает историю пропсами (why/what/where/when/how), а не only-текст.
- [ ] Foreshadowing связок между уровнями (напр. нити Путало заранее).

### D. Game feel / juice
- [ ] Фидбэк на КАЖДОЕ действие: частицы + звук + анимация/сквош.
- [ ] Никаких резких pop-in — появление через fade/anticipation.
- [ ] NPC живые: idle-покачивание, реакция на игрока.
- [ ] Награда = конфетти + фанфары + reward-pop карточка.

### E. Звук (полный)
- [ ] Фоновая музыка мира (лес / зима), тихая, зацикленная, mute-совместимая.
- [ ] SFX: шаги, сбор, успех, ошибка(мягкая), клик UI, открытие сундука.
- [ ] Голос-подсказки Барсика / NPC на ключевых beat (RU + KK), с сабами.
- [ ] Всё уважает `prefers-reduced-motion` и настройку mute.

### F. Адаптив & производительность
- [ ] Телефон (портрет) + планшет + десктоп: HUD и джойстик не перекрывают экшн.
- [ ] 60 fps на десктопе, ≥30 fps на среднем телефоне (тени/pixelRatio деградируют).
- [ ] Корректный dispose (нет утечек geometry/material/texture между уровнями).

### G. Локализация & доступность
- [ ] RU + KK вычитаны носителем-канона (никакого машинного/утёкшего японского).
- [ ] Текст крупный, минимальный; иконки дублируют смысл для 3–5 лет.

## 4. Флагман (эталон-планка) = **Mission 0 «Первое утро»**

Почему L0: первое, что видит игрок; уже самая богатая сцена (1977 стр); а
процедурный Барсик + аудио, построенные здесь, каскадом улучшают все 16.

Флагман считается принятым, когда проходит §2 (весь чек-лист) + закрыты все
P0/P1 из `MISSION0_AUDIT.md`. Затем — раскатка планки на L1–L16.

## 7. Рабочий цикл (из Level Design Book: plan→layout→blockout→production→release)

Для каждого уровня при доводке:
1. Сверить с GDD-сценарием (эксп-цели «игрок должен …»).
2. Blockout уже есть (сцена) → проверить critical/golden path, метрики.
3. Production: juice, аудио, NPC, средовое повествование, адаптив.
4. Плейтест-замер 4–6 мин; починить soft-lock/тупики/клиппинг.
5. Прогнать §2 чек-лист → отметить ✅ в §6.
