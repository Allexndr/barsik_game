## Полный список экранов

### 1. SPLASH / LOADING
- Анимированный логотип
- Прогресс-бар загрузки ассетов
- Автопереход: Login (первый раз) или Main Menu

### 2. LOGIN / ONBOARDING
- Фон: размытый фон меню
- Карточка: «Привет! Я Барсик!»
- Инпут: имя игрока
- Кнопка: «Начать приключение!»
- Переход: → Main Menu

### 3. MAIN MENU (Home)
- Фон: parallax меню-фон + vignette
- Top HUD: ⭐ звёзды, 🐱 друзья, ⚙️ настройки
- Центр: Барсик (floaty animation), заголовок
- Кнопки: Играть, Город, Друзья, Сундук, Рейтинг, Профиль, Задания, Пригласить
- Нижний навбар: Главная | Карта | Друзья | Задания | Профиль

### 4. DIFFICULTY SELECT
- 3 карточки: Лёгкое / Смелое / Супер
- Описание каждого режима
- Выбор → переход на Карту

### 5. MAP
- Большая карта путешествия
- 6 миров с пинами
- Блокировка/открыто/пройдено
- Тап на мир → Levels

### 6. LEVELS
- Сетка уровней мира (по 4 в ряд)
- Статусы: заблокирован / открыт / пройден
- Иконка друга на каждом 5-м уровне
- Тап на уровень → Game

### 7. GAME (Gameplay)
- Canvas: parallax фон, 3 дорожки
- HUD: пауза, уровень, прогресс, звёзды
- Управление: свайп/клавиши/тап
- Бустеры: индикаторы активных
- Оверлеи: Pause, Result (победа/поражение)

### 8. CITY OF FRIENDS
- Фон города (развивается с друзьями)
- Объекты появляются: домики, парк, кафе, фонтан...
- Статистика внизу: друзей / зданий
- Тап на объект → информация

### 9. COLLECTION (Друзья)
- Сетка всех 20 друзей
- Редкость: common / rare / legendary
- Заблокированные — силлуэт
- Тап → Friend Detail (подэкран)

### 10. FRIEND DETAIL (подэкран Collection)
- Большой эмоджи друга
- Имя, редкость, описание
- Где найти (мир, уровень)
- Кнопка «Назад»

### 11. QR CHEST
- Интро: инструкция + сундук
- Анимация открытия: фейерверк, шарики
- Награда: друг / костюм / бустер / звёзды
- Дубль → автоматическая замена
- Счётчик открытых

### 12. RATING
- 3 таба: Неделя / Месяц / Исследователи
- Дружеский список (без проигравших)
- Авто-обнуление периодически

### 13. PROFILE
- Аватар + имя + костюм
- 7 показателей статистики
- Магазин костюмов (6 штук)
- Магазин эмоций (6 штук)
- Инвентарь бустеров (3 типа)
- Реальные призы (5 порогов)

### 14. TASKS
- 6 ежедневных заданий
- Прогресс-бар на каждом
- Кнопка «Забрать» при завершении
- Сброс каждый день

### 15. INVITE FRIENDS
- Уникальная ссылка
- Кнопки: Копировать, Поделиться
- Статистика: приглашено / бонус
- +10⭐ за каждого друга

### 16. SETTINGS
- Имя игрока (редактирование)
- Звук вкл/выкл
- Сброс прогресса (с подтверждением)

## Логические пути (User Journeys)

### Путь новичка
```
Splash → Login → Main Menu → Difficulty → Map → World 1 → Level 1
→ Победа → Level 2 → ... → Level 5 → Новый друг! → Collection (виден друг)
→ Main Menu → City (виден домик) → Tasks → Забрать награду
```

### Путь возвращающегося
```
Splash → Main Menu → «Барсик скучает!» → Daily Bonus
→ Tasks → Играть → Map → следующий уровень → ...
```

### Путь коллекционера
```
Main Menu → Collection → недостающие друзья → Игра до 5 уровня
→ Новый друг → Collection → City → новый дом
→ QR Chest → редкий друг → Collection
```

### Путь социального
```
Main Menu → Invite → копировать ссылку → друг зашёл → +10⭐
→ Rating → команда → Tasks → забрать награды
```

### Путь призовой
```
Main Menu → Profile → Реальные призы → видно: 20 ур = наклейки
→ Играть до 20 уровня → Приз! → Profile → следующий приз
```

## Дополнения из Плана развития (для будущих версий)

### Сезонные события
- Лето: летний сезон, летние костюмы
- Зима: новогодний, зимние друзья
- День защиты детей: спецсобытия
- Наурыз: уникальные костюмы

- Создание команды
- Командный флаг
- Совместные события
- Обмен подарками (без торговли)
- Командные турниры

### Расширенная коллекция
- 40 друзей (вместо 20)
- 120 костюмов
- 300 предметов города
- 80 достижений

### Админ-панель (отдельно)
- Добавление уровней/друзей
- Запуск сезонных событий
- Загрузка QR-серий
- Аналитика и статистика
